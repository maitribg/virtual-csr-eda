# CSR Simulator - Presentation UI

A beautiful, modern web interface to present customer service representative (CSR) training simulations and analysis.

## Overview

This presentation UI displays:
- Customer profiles with background information
- Full conversation transcripts in chat format
- Performance analysis with scores and insights
- Key learning moments and actionable recommendations

## Features

- **3 Customer Scenarios**: Angry, Unsatisfied, and Confused customers
- **Interactive Navigation**: Click on any customer card to view their details
- **Chat-Style Transcript**: Easy-to-read conversation format
- **Performance Metrics**: Visual scoring and detailed analysis
- **Professional Design**: Clean, modern UI perfect for academic presentations

## How to Use

1. Open `index.html` in any modern web browser
2. Click on any of the three customer cards at the top:
   - **Alex Johnson** (Angry Customer) - Card acceptance issues
   - **Alex Jordan** (Unsatisfied Customer) - Billing dispute
   - **Jordan Smith** (Confused Customer) - Scheduling mishap
3. View the complete customer profile, conversation, and analysis

## Files

- `index.html` - Main HTML file with the UI structure
- `data.js` - Customer data including profiles, dialogues, and analyses
- `app.js` - JavaScript for UI interactions and data loading
- `README.md` - This file

## Technical Details

- **Framework**: Pure HTML/CSS/JavaScript
- **Styling**: Tailwind CSS (via CDN)
- **No Build Required**: Just open index.html in a browser
- **Responsive Design**: Works on desktop and tablet devices

## Data Source

All data is sourced from the CSR simulator training sessions:
- Chat conversations from JSON files
- Performance analyses from analysis files
- Customer profiles from training scenarios

## Presenting to Professors

This UI is specifically designed for academic presentations:
- Clean, professional appearance
- Clear data visualization
- Easy navigation between scenarios
- Comprehensive analysis display

Simply open the HTML file and navigate through the customers during your presentation.
